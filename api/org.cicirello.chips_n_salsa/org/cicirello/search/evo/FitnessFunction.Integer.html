public static interface FitnessFunction.Integer<T extends Copyable<T>> extends FitnessFunction<T>
Fitness function interface for int-valued fitnesses. Implement this interface to provide a fitness function for use by genetic algorithms and other forms of evolutionary computation. Some of the SelectionOperator classes of this library assume that fitness values are positive, so for maximal compatibility, you should design your fitness function such that fitness values are always positive.
